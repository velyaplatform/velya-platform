# Hook Model Framework

By Nir Eyal. Framework for building habit-forming products.

## Core Principle

```
Trigger -> Action -> Variable Reward -> Investment
    ^                                      |
    +--------------------------------------+
```

## The Four Phases

### 1. Trigger
- External (push notifications, emails, buttons) initiate behavior early
- Internal (emotions: boredom, loneliness, FOMO) are the ultimate goal
- Map your product to the specific negative emotion it resolves
- Goal: move users from external to internal triggers over time

### 2. Action (B = MAT)
- Behavior = Motivation x Ability x Trigger
- Reducing friction > increasing motivation
- Six elements of simplicity: time, money, physical effort, brain cycles, social deviance, non-routine
- Core action completable in seconds

### 3. Variable Reward
- Dopamine spikes during anticipation, not upon receiving
- Three types: Tribe (social), Hunt (resources/info), Self (mastery)
- Predictable rewards lose power; variability sustains engagement
- Autonomy is critical -- forced engagement backfires

### 4. Investment
- IKEA effect: users value what they invest effort into
- Creates switching costs (data, content, reputation, skill, social)
- Investment comes AFTER reward, not before
- Each investment loads the next trigger

## The Manipulation Matrix

| | Maker Uses Product | Maker Doesn't |
|--|----|----|
| **Improves Life** | Facilitator | Peddler |
| **Doesn't Improve** | Entertainer | Dealer |

## Quick Diagnostic

| Question | If No | Action |
|----------|-------|--------|
| What's the internal trigger? | Users need reminders | Research user emotions |
| Is the action dead simple? | Users don't complete | Remove friction |
| Is the reward variable? | Users get bored | Add unpredictability |
| Does investment load next trigger? | Users don't return | Connect investment to triggers |
