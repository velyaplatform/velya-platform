# Design Sprint Framework

A five-day process for answering critical business questions through design, prototyping, and testing ideas with customers. Developed at Google Ventures.

## Core Principle

**Great solutions require both deep work and fast iteration.** The Design Sprint compresses months of debate, design, and testing into a single week.

## The 5-Day Sprint Process

```
Monday -> Tuesday -> Wednesday -> Thursday -> Friday
  Map      Sketch     Decide      Prototype    Test
```

## Monday: Map

- Write the sprint question: "What do we want to be true in 2 years?"
- List obstacles and unknowns as questions
- Map the customer journey (5-15 steps)
- Ask the Experts: interview team members
- HMW (How Might We) notes: rephrase problems as opportunities
- Pick a target customer and moment

## Tuesday: Sketch

- Lightning Demos: find inspiration from competitors and analogous products
- Four-Step Sketch (individual work, NOT group brainstorming):
  1. Notes (20 min)
  2. Ideas (20 min)
  3. Crazy 8s (8 min) - 8 variations in 8 minutes
  4. Solution Sketch (30-90 min) - 3-panel storyboard

## Wednesday: Decide

- Art museum: tape sketches to wall, silent review with dot stickers
- Heat map review: 3 min per sketch
- Straw poll: each person votes for one solution
- Decider supervotes (3 large dots)
- Create 10-15 panel storyboard for prototype

## Thursday: Prototype

- Assign roles: Makers, Stitcher, Writer, Collector, Interviewer
- Build a realistic facade (Figma, Keynote, etc.)
- Goldilocks quality: looks real, doesn't work real
- Trial run with someone not on sprint team

## Friday: Test

- Five-Act Interview (30 min each):
  1. Friendly Welcome (5 min)
  2. Context Questions (5 min)
  3. Introduce Prototype (5 min)
  4. Tasks and Nudges (15 min)
  5. Debrief (5 min)
- 5 customers, pattern recognition with checkmarks/crosses
- End-of-sprint debrief: what worked, what failed, next steps

## When to Run

- High-stakes decision
- Team stuck in endless debate
- Multiple solutions possible
- New product, feature, or major redesign
- Need to de-risk before investing
